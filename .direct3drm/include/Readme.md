# What goes here

This folder needs to include the following files that are not included in the repo due to licensing:

- `d3drm.h` Not found in the win32Metadata Project, but can, for example, be found in a mingw distribution.
- `d3drmdef.h` Not found in the win32Metadata Project, but can, for example, be found in a mingw distribution.
- `d4drmobj` Not found in the win32Metadata Project, but can, for example, be found in a mingw distribution.
